3D to 2D Projection Demo

3D to 2D Projection Math

1. Vector Operations

• Dot product: a·b = axbx + ayby + azbz

• Cross product: a×b = (aybz-azby, azbx-axbz, axby-aybx)

2. View Matrix (LookAt)

Constructed from:

• Forward vector (z): Normalized(eye - target)

• Right vector (x): Normalized(up × z)

• Up vector (y): z × x

3. Projection Matrix

Perspective projection with:

• Field of View: 75°

• Aspect Ratio: canvas width/height

• Near/Far planes: 0.1 to 100 units

4. Projection Pipeline

  1. Model → World space (modelMatrix)
  2. World → Camera space (viewMatrix)
  3. Camera → Clip space (projectionMatrix)
  4. Perspective divide → NDC [-1,1]³
  5. NDC → Screen coordinates
